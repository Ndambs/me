        Connect publishing

        Publishing saves your post as files in your GitHub repository, which GitHub Pages then serves. One-time setup per browser.

        1. Open GitHub → New fine-grained token.
        2. Set Repository access to Only select repositories and choose .
        3. Under Permissions → Repository, set Contents to Read and write.
        4. Generate the token and paste it below.

        The token stays in this browser only and is sent only to api.github.com. Use a token limited to this one repository.
